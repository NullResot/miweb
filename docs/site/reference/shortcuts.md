# 快捷键

先选择画布中的元素。输入框、弹窗或代码交付窗口获得焦点时，页面快捷键会暂停，避免误改。

| 快捷键 | 操作 |
| --- | --- |
| 方向键 | 移动选中元素 1 px |
| Shift + 方向键 | 移动选中元素 10 px |
| Alt + 左 / 右 | 减少 / 增加宽度 1 px |
| Alt + 上 / 下 | 减少 / 增加高度 1 px |
| Alt + Shift + 方向键 | 以 10 px 步长调整宽高 |
| Ctrl + Z | 撤销 |
| Ctrl + Shift + Z | 重做 |
| Ctrl + Y | 重做 |
| Esc | 取消选择 |
| Ctrl + S | 显示当前界面保存状态，不写回项目源码 |

在支持的平台源码版中，⌘ 对应 Ctrl。

拖动过程中可按 Esc 取消这次拖动。对比状态下暂停修改。

鼠标操作与属性输入见 [选择与调整](/guide/edit)。
