# 常见问题

## 需要 AI 账号或 API Key 吗？

不需要。Miweb 使用本机渲染器与源码定位完成微调，不调用 AI 模型。打开公开网页时仍需网络。

## 能从任意网址导出原始 React / Vue 代码吗？

不能。网址提供的是渲染后的页面，Miweb 导出 CSS 或 JavaScript 布局补丁。导入受支持的原始项目，才能生成与原文件对齐的源码修改。

## 会直接修改我的项目吗？

不会。项目读取和预览是只读的。修改后的源码、diff 与补丁由你复制、下载，再在原项目中审查和应用。

## 为什么本地项目导入失败？

先检查所选目录是否包含 `index.html`，项目引用的其他 npm 包是否已经安装。默认支持普通 HTML、Vite React / Vue 与 `@/` 别名。

自定义插件、其他路径别名、Next.js 或特殊构建不能保证直接预览。先在原项目中启动开发服务，再输入 localhost 链接。详见 [导入页面与项目](/guide/import)。

## 为什么打开 localhost 链接失败？

确认开发服务正在运行，地址与端口正确，并能在同一电脑的浏览器中打开。桌面版中的 `localhost` 指运行 Miweb 的电脑。

局域网服务还需要目标电脑允许网络访问，开发服务监听的地址也不能仅限目标电脑自己的 `127.0.0.1`。

## 为什么登录后的页面、Canvas 或交互效果没有出现？

捕获不复用你日常浏览器的登录状态。登录限制、反自动化、Canvas、Shadow DOM、跨域内嵌与依赖实时交互的内容，可能无法完整捕获。

画布使用当前地址的渲染快照，导入后暂停原页面脚本与导航。Miweb 不是完整的交互测试浏览器。

## 为什么拖动后大小或位置受限？

原页面的 Flex / Grid、min/max-width、父级裁剪和元素类型约束仍然有效。Miweb 不会为绕过它们自动改变 DOM 结构。选择父容器或在原项目中检查约束。

## 修改只对当前预览宽度生效吗？

默认修改作用于所有屏幕宽度。切换预览用于检查影响，不会自动生成媒体查询。需要只在某个断点生效时，请在原项目的响应式样式中整理输出。

## 为什么一个元素修改后，几个组件一起变化？

这些实例映射到同一处源代码定义。修改该定义会影响全部实例，属性面板会显示提示。需要独立外观时，在原项目中为实例增加独立参数或样式。

## 关闭后还能恢复吗？

界面保存调整记录，但预览会话不是长期项目存储。退出应用、服务重启或空闲会话过期后需要重新导入。会话默认空闲有效期 120 分钟。

请在结束前复制或下载结果，避免将临时预览当作代码备份。

## 项目会上传到 Miweb 的服务器吗？

桌面版的项目预览和页面处理在本机进行，不需要连接 Miweb 的远程处理服务。项目或目标网页自身引用的网络资源仍可能产生对外请求，例如在线字体、图片和 CDN 依赖。

## 文档网站可以直接编辑页面吗？

不能。GitHub Pages 托管的是静态文档，不运行项目渲染器。下载桌面版后在本机编辑；开发者也可以从源码运行编辑器。

## 如何反馈问题？

在 [GitHub Issues](https://github.com/NullResot/miweb/issues) 提供应用版本、导入方式、复现步骤与实际结果。尽量附最小示例，提交前移除访问密钥、个人信息与不能公开的项目内容。
