# 导入页面与项目

可以导入本地项目，也可以输入已运行页面的链接。两种方式都能微调布局，区别在于是否拥有可关联的原始源码。

## 本地项目

点击开始页的“选择项目文件夹”，或顶栏的“本地项目”。桌面版会直接打开系统文件夹选择器，选择项目根目录即可。也可以在输入框中填写完整目录路径：

```text
D:\projects\my-site
```

目录模式只读加载文件，不会覆盖原项目，不会执行项目的 npm 脚本或自定义构建配置。

### 支持的项目

项目需要包含 `index.html` 入口，支持：

- 普通 HTML 与本地 CSS。
- Vite React，使用 JSX 或 TSX。
- Vite Vue，使用 Vue 单文件组件。
- 默认的 React / Vue 模块，以及 `@/` 路径别名。

项目引用其他 npm 包时，这些依赖需要已安装在该项目的 `node_modules` 中。Miweb 不会自动执行项目的依赖安装。

Next.js、特殊路径别名、自定义 Vite 插件或其他复杂构建，请先在原项目里启动开发服务，再输入它的本地链接。此时导出的是布局补丁。

### 文件夹上传

从浏览器运行源码版时，文件夹选择会将项目文件导入临时预览。上传会排除 `node_modules`、`.git`、常见构建产物与 `.env` 等敏感文件。

上传内容依赖其他 npm 包时，可能无法完整预览。桌面版优先使用原生目录选择，保留对项目已安装依赖的访问。

## 本地开发链接

在原项目中启动开发服务，再把地址粘贴到 Miweb，例如：

```text
http://localhost:5173
http://127.0.0.1:3000
http://192.168.1.20:8080
```

`localhost` 指运行 Miweb 的电脑。局域网地址需要当前电脑能访问对应服务，服务也需要监听可访问的地址。

链接模式不连接源文件。即使网页来自你的本地 React / Vue 项目，Miweb 也会导出 CSS 或 JavaScript 补丁；要导出原文件修改，请使用受支持的目录模式。

## 网页链接

输入公开网页的完整 URL：

```text
https://example.com
```

Miweb 加载并捕获这个地址的当前页面，不抓取整个站点或子页面，也不使用你日常浏览器里的登录状态。

预览中的原页面脚本、链接导航和表单交互会暂停，方便选中与微调。页面依赖登录、反自动化或特殊交互时，导入结果可能不完整。

## 导入失败时

先在当前电脑的浏览器中确认链接能打开。目录模式确认根目录包含 `index.html`，其他包依赖已经安装。

如果项目依赖自定义插件或特殊构建，先启动它自己的开发服务，再使用本地链接。导入失败会显示错误，并保留已有画布和调整。

更多排查见 [常见问题](/reference/faq)。
