# 选择与调整

导入后，在画布中选择元素。你可以拖动，使用方向键，或在属性面板中输入具体数值。

## 选择元素

- 点击画布中的按钮、文字或容器。
- 从元素列表中选择，或搜索元素。
- 使用“选择父元素”，调整整个容器。
- 按 Esc 取消选择。

有源码关联时，属性面板会显示对应文件信息。页面运行时动态生成的元素可能无法匹配源码，此类改动通过布局补丁带走。

同一个源元素渲染为多个组件实例时，改动会同步到这些实例，界面会提示受影响数量。它们在源码中对应同一处定义。

## 位置与尺寸

拖动选中的元素改变位置；拖动选中框的八个控制点改变宽高。

| 操作 | 结果 |
| --- | --- |
| 方向键 | 移动 1 px |
| Shift + 方向键 | 移动 10 px |
| Alt + 左 / 右 | 减少 / 增加宽度 1 px |
| Alt + 上 / 下 | 减少 / 增加高度 1 px |
| Alt + Shift + 方向键 | 以 10 px 步长调整尺寸 |

X / Y 是相对原位置的偏移，移动使用 CSS `translate`，保留原来的 `transform`。宽高以 border-box 像素计算。

## 属性面板

可以直接输入 X / Y 偏移、宽度、高度、字号与圆角。输入有效数值后，画布立即显示调整结果。

调整目标应尽量小而明确。例如，只放大按钮时选择按钮；希望一组内容一起移动时选择其父容器。

## 撤销、恢复与对比

- “撤销 / 重做”在当前调整历史中移动。
- “恢复元素”移除选中元素的修改。
- “清空调整”恢复整个页面的导入状态，仍可通过撤销找回这次操作。
- “对比”查看调整前的页面，对比状态下暂停编辑。

这些操作改变的是 Miweb 里的调整记录，不会写回原文件。

## 布局与预览

使用桌面、平板或手机宽度预览，也可以缩放画布。不同宽度用于检查效果，**不会自动生成响应式断点或只在当前宽度应用修改**。

Flex / Grid、min/max-width、父级裁剪和内联元素等原有布局约束仍然生效。若元素受约束无法达到预期尺寸，检查原项目样式；Miweb 不会为了绕过约束自动重写结构。

## 保存调整

调整保存在当前应用的界面存储中，预览会话由本机服务维护。退出应用、服务重启或会话过期后，可能需要重新导入。请在结束前 [复制或下载结果](/guide/export)。
