# 第一次微调

用内置示例完成一次调整，了解从页面到代码的完整流程。

## 打开示例

打开 Miweb，点击“试用示例”。示例是项目自带的 HTML 页面，已连接源码，可以查看修改后的文件与最小 diff。

等待画布加载后，在页面中点击一个按钮。选中框会标出元素，属性面板会显示位置、尺寸与对应源码信息。

## 移动与放大

1. 按一次方向键，让按钮移动 1 px。
2. 按住 Shift 再按方向键，让按钮移动 10 px。
3. 拖动选中框的控制点，调整按钮宽度。
4. 在属性面板中输入具体数值，让结果更精确。

拖动改变位置，控制点改变尺寸。X / Y 是相对于导入时位置的偏移；宽高是像素尺寸。

## 检查变化

使用“对比”查看调整前后的差别，再切换桌面、平板或手机宽度检查布局。

预览宽度不会给改动自动生成媒体查询。这次调整默认作用于所有屏幕宽度，详见 [布局与预览](/guide/edit#布局与预览)。

不满意时点击“撤销”，或者恢复选中元素。操作不影响示例文件或你自己的项目。

## 带走代码

点击“复制代码”复制修改后的源码，也可以打开交付窗口查看源码、diff 和 CSS 补丁，下载需要的结果。

在自己的项目中使用时，先检查 diff，再替换对应文件或应用补丁。Miweb 不会直接写回原项目。

完成后可以 [导入自己的页面](/guide/import)。如果你只输入一个网页链接，按钮会显示“复制补丁”，导出的内容也会变为布局补丁。
