# Miweb Gallery 设计

## Direction

本次为用户明确要求的视觉重设计。保留产品名称、标志结构、网址输入、文件夹接入和工作台功能，将旧版蓝灰双栏首页替换为 Apple 参考中的白色产品展厅。

首页访客任务：理解它如何完成几处小修改，并直接打开页面。工作台访客任务：清楚、准确、快速地编辑。

## Tokens

- 背景 #ffffff；章节带 #f5f5f7；次级面 #fafafc。
- 正文 #1d1d1f；次级文字 #707070；发丝线 #d6d6d6。
- 唯一操作强调 #0071e3；文字链接 #0066cc。遵循用户追加的苹果科技风要求，演示内容同步使用冷白、银灰和精密蓝色标记。
- 字体用系统 Apple/SF 对应的系统字体栈，Windows 用 Segoe UI / Microsoft YaHei；不请求外部字体。
- 大标题桌面 80px / 600，手机 44px；展示媒体 28px 圆角，按钮胶囊，编辑器小控件维持适宜的小圆角。
- 不使用渐变、不加投影、不堆叠同样大小的功能卡。

## Surface contract

**Scope / mode:** 首页 Persuade，真实编辑器 Operate。平台 Web。

**First viewport:** 安静的标志导航，桌面一行居中大标题（手机两行），简短用途说明，立即可用的网址输入和现有示例入口；银灰产品展示尽早进入首屏。核心输入在首屏可见。

**Visitor path:** 输入地址直接进入，或向下浏览一次完整示意操作；之后查看源码与网址的交付区别，返回输入入口。

**Signature interaction:** 首页下方白灰舞台固定于原生滚动视口，游标选择按钮，向上移动12px并放宽，然后展示局部样式改动。三个步骤按钮提供键盘和减少动态效果的替代入口。

**Proof:** 使用可渲染的 HTML 演示组件与实际工作台示例，不使用虚构客户、数字或评论。

**Constraints:** 不劫持滚动，不加载视频或动效依赖；动画仅在展示区工作，支持 reduced motion。保留错误态、历史记录、文件夹导入以及全部编辑/导出行为。

## Skill application

Impeccable：产品/设计上下文分离、首页与操作界面不同节奏、清晰对比度、有目的的唯一动效、桌面/手机批量检查。

Taste Skill：Redesign Overhaul；DESIGN_VARIANCE=4、MOTION_INTENSITY=6、VISUAL_DENSITY=2，原因是用户锁定苹果式居中白色布局，并指定操作演示。技能中的暗色模式、换字体和随机视觉方向建议不覆盖用户明确的浅色参考。采用代码实现产品演示；不将这个实现选择写为用户的长期工作流偏好。
